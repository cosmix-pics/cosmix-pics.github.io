OBS ORA puppet

a neat PNGtuber-like avatar to puppeteer in OBS using the OpenRaster format

installation

add flag (windows)

  1. right-click your OBS Desktop shortcut and select Properties.
  2. locate the Target field.
  3. add a space at the end, then paste the flag below:
    4. --enable-media-stream

    the result should look like: "C:\Program Files\obs-studio\bin\64bit\obs64.exe" --enable-media-stream

add controls

  1. run OBS.
  2. navigate to View → Docks → Custom Browser Docks...
  3. set Dock Name to something like ORA Puppet.
  4. paste the following URL:
    5. https://cosmix.pics/ORA?control=1
  5. click Apply, then dock the window anywhere you want
  6. in Sources panel, click + then Browser.
  7. set the URL to:
    8. https://cosmix.pics/ORA
  8. set Width and Height to prefrence, example 1900 x 1080
